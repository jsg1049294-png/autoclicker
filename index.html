⚠️ Wichtige technische Grenze

Eine normale Webseite (auch diese) darf aus Sicherheitsgründen keine Klicks in anderen Tabs, anderen Apps oder systemweit auslösen. Das ist von Apple und allen Browsern so vorgesehen.

  • In dieser Seite: Der AutoClicker funktioniert vollständig (Demo unten).
  • Auf jeder anderen Website: Nutze das Bookmarklet – es injiziert den gleichen AutoClicker direkt in die geöffnete Seite.
  • Systemweite Klicks oder Steuerung anderer Apps sind mit reinem Web-Code auf iPadOS nicht möglich. Dafür bräuchte man eine native App mit speziellen Berechtigungen (App Store).

Bookmarklet – für jede Website

Das Bookmarklet lädt den AutoClicker in die gerade geöffnete Seite. Danach kannst du Positionen antippen und starten – genau wie hier.

  1. Kopiere den Bookmarklet-Code (Button unten).
  2. Auf dem iPad: In Safari eine beliebige Seite öffnen → Teilen → „Lesezeichen“ / „Zu Favoriten“.
  3. Lesezeichen bearbeiten → Adresse komplett durch den kopierten Code ersetzen → Speichern.
  4. Auf der gewünschten Website das Lesezeichen antippen → AutoClicker erscheint.

Tipp: Favoritenleiste in den Safari-Einstellungen aktivieren, dann ist der AutoClicker schneller erreichbar.

So benutzt du den AutoClicker

  1. Fenster erscheint (oder tippe „AutoClicker öffnen“).
  2. „Klickposition auswählen“ → auf die Stelle tippen, die geklickt werden soll.
  3. Intervall und Anzahl einstellen.
  4. Start → Pause / Stop nach Bedarf.
  5. Fenster per Titelleiste verschieben, minimieren (−) oder schließen (×).
